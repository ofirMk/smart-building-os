## פרק 1 — פתיחת הזמנת רכש (00:00–03:03)

**ניווט**: `רכש › הזמנות רכש`.

**Header — auto-fill on supplier select**:
- `מס' ספק *` — בחירת הספק.
- `תאריך *`, `מס' הזמנה *`, `שם ספק` — מתמלאים אוטומטית.
- `איש קשר` — מתמלא לפי איש הקשר שהוגדר **לטיפול בהזמנות** אצל הספק
  (שדה/דגל ייעודי על ה-contact). ניתן לשינוי.

**6 לשוניות ראשיות**:

### 1.1 מחירים
- `מטבע *` — מטבע ברירת מחדל של הספק (overridable).
- `הנחה כללית (%)` — per-order override.
- חישוב: `מחיר כולל` → `הנחה` → `מחיר אחרי הנחה` → `מע"מ` → `מחיר
  כולל מע"מ`.

### 1.2 אסמכתאות
- **`מחסן מקבל`** → מאכלס אוטומטית את `כתובת למשלוח` sub-screen;
  הכתובת הזו **מודפסת על ה-PO**.
- **`סוג הזמנה`** → FK לטבלת `סוגי הזמנת רכש` (A/B/C/D במערכת
  הדגמה). **F6 פעמיים** → הוספת סוגים חדשים + **טקסט קבוע דו-לשוני**
  (עברית + אנגלית) לכל סוג.
- `הצעת מחיר` + F6 → רשימת הצעות מאושרות ובתוקף של הספק (Blanket).
- `הזמנת לקוח` + F6 → מסך `הזמנות לקוח` → F8 = חזרה עם link. או
  מסך-בן `הזמנות לקוח להזמנה` לריבוי קישורים.
- `דרישה מרוכזת` — link ל-Purchase Demand.
- `הזמנת מסגרת` — link ל-Blanket PO.
- `סוג תוק יבוא/יצוא` — סיווג לייבוא.
- **Sub-screen `כתובת למשלוח`**: שדות עברית + אנגלית במקביל.
- **Sub-screen `הזמנות רכש – טקסט`**: rich-text HTML (Font/Size/Color/
  Bold/Italic/Align/Lists/Link). Prefill מטקסט הסוג או מברירת הספק.
- **Sub-screen `נספחים`**: attachments עם columns `שם קובץ · מספר
  מאפיין · נתיב · תאריך יצירה · גודל (בתים) · סיומת · משלח · שורק
  ע"י · ת. עדכון אחרון`.

### 1.3 פרויקט
קישור לפרויקט/חשבון.

### 1.4 אישורים ומעקב ביצוע
- `סטטוס *` — מה-workflow (ראה פרק 3).
- `לטיפול` — המאשר הבא בתור.
- `רשימת מאשרים` + `תואר רשימה` — FK ל-`רשימות מאשרי הזמנות רכש`.
- `החתום הבא` — next signatory.
- `מאושרת?` — flag.
- `מהדורה נוכחית` — revision number.
- `הדפסה`, `ניתנת לשינוי?`, `סתרות?`, `סגורה חלוקת`, `משפיעה על
  התכנון`, `דרוש הרשאה לספק`, `לקוח בלבד?`, `הודית` (priority level).

### 1.5 תנאים כספיים
- `קוד מע"מ` — auto-fill מהגדרות הספק (ברירת מחדל `002` = "מע"מ
  תשומות").
- `מטבע הצמדה`, `שער בסיס`, `שער מקורה`, `% ניכוי מקור`.
- **`תנאי תשלום`** — FK לטבלת קודים (seed):

  | קוד | תאור |
  |---|---|
  | 01 | שוטף |
  | 02 | 90 ימים |
  | 03 | 15 ימים |
  | 04 | 45 ימים |
  | 05 | 30 ימים |
  | 06 | 60 ימים |
  | 07 | 120 ימים |

- `ביצוע מקוטע`, `לא נכללות בתחריב?`, `תנאי תשלום להוצמה?`.

### 1.6 שונות
שדות נוספים (לא מוצגים בפירוט ב-reference).

## פרק 2 — פירוט ההזמנה (03:04–05:03)

**ניווט**: sub-screen `פירוטי הזמנת רכש` של ה-PO.

### 2.1 Item picker hierarchy
- **F6 על `מק"ט`** → רשימת **מוצרים של הספק בלבד** (מ-`מוצרים לספק`
  sub-screen של הספק).
- **`Ctrl+F6`** → **רשימה מלאה** של כל המוצרים (fallback).
- אפשר לבחור גם דרך `מק"ט ספק/יצרן`.

### 2.2 שדות שורה חובה
`מק"ט *` · `כמות *` · `ת. אספקה *` · `מחיר ליחידה`.

### 2.3 עמודות שורה מלאות
`מק"ט · תאור מוצר · כמות · יתרה לאספקה · יחידה · ת. אספקה · מחיר
ליחידה · מקור מחיר · מטבע · הנחה (%) · סה"כ מחיר · מחיר כולל מע"מ ·
מק"ט ספק/יצרן · תאור מק"ט ס.ספק · שם יצרן · שם מלא יצרן`.

### 2.4 Price waterfall (F1 help)
מחיר ליחידה נבחר לפי hierarchy:
1. **מחירון/הצעת מחיר של הספק** (agreed item price).
2. **מחירון הספק** הכללי.
3. **מחיר הרשום בכרטיס הפריט**.
4. **ה-PO האחרון** של אותו ספק — **תוך `PPriceDays` ימים**
   (system parameter).

Manual override תמיד אפשרי. **`מקור מחיר`** column מציג מהיכן נלקח.

### 2.5 Line sub-tabs (13 sub-tabs)
- `פירוטי הזמנת רכש` · `פירוט דגמים` · `כמות לוח להזמנה` · `כתובת
  למשלוח` · `אישור הזמנת הרכש` (line-level approval) · `מהדורות
  הזמנת רכש` (line revisions) · `פירוט הצעה` · `קישור לפרויקט/חשבון`
  · `הזמנות רכש – טקסט` · `פירוט הספק` · `הערות פנימיות` · `שונות`.

### 2.6 שדות ב-`מהדורת מוצר` (sub-tab)
- **`סעיף תקציבי *`** — budget code. **תעודות המבוססות על PO זה יורשות
  את הסעיף**.
- `תאריך ניצול תקציב` · `סג עלות יבוא (L/S/A)` · `מספר דרישון` ·
  `הזמנת לקוח + שורת הזמנת לקוח` · `סטטוס שורת הזמנת רכש` · `דרגת
  הרשאה למוצר` · `כמות מפעל`.

### 2.7 Decision support — Bottom sub-screens (12)
- `סה"כ ההזמנה` · `קישור לפרויקט/חשבון` · `מאפיינים לקוד סל` · `פירוטי
  הזמנת רכש – טקסט חופשי` · **`זמינות מוצר מרכזי`** · **`זמינות פריט
  מרכז`** · **`מלאי למוצר`** · **`מעקב תנועות`** · **`הצעות מחיר
  למוצר`** · **`חשבוניות`** · **`קישור תקלה`** · `הזמנות לקוח
  לדרישיות/הזמנות רכש`.

### 2.8 Projected inventory (sub-screen `זמינות מוצר`)
- `מלאי זמין` · `הזמנת רכש` (open PO qty) · `הזמנת לקוח` (open SO qty)
  · **`מלאי צפוי`** = `זמין + PO − SO`.
- דוגמת הסרטון: `0 + 100 − 35 = 65`.

### 2.9 Line-level actions (`הפעלות ישירות` מתוך שורה)
- **חישב רכש למוצר** — calculate purchase need per product.
- **ערכי מחיר אחרון** — last-price lookup (jump to prior order).
- **פיצול שורת הזמנת רכש** — split line to multiple delivery
  dates/quantities.
- **סגירה — דו"ח שגיאות** — close with error report.

## פרק 3 — אישור הזמנה (05:05–08:10)

### 3.1 `רשימת מאשרים` (Approvers List)
- Header table: `code`, `description`, `is_inactive`. ברירת מחדל `00`
  = "מאשרי הזמנות רכש – כללי".
- Detail lines:

  | `*החל מסכום` | `מטבע` | `*שם מאשר` | `מאשר חלופי` |
  |---|---|---|---|
  | 0.00 | ש"ח | יואב (מנהל אזור) | — |
  | 10,000.00 | ש"ח | סיגל כהן (מנהלת תפעול) | — |

- **`מאשר חלופי`** (backup) לכל שלב.

### 3.2 Approval sub-screen על PO (`אישור הזמנת הרכש`)
Grid דינמי שנוצר מהתבנית. עמודות:
`מטבע · החל מסכום · *שם מאשר · מאשר חלופי · אושר ☐ · אישר ע"י ·
תאריך אישור`.

### 3.3 Status transitions — הזרימה הסטנדרטית
```
טיוטא → מחכה לאישור → (email to 1st approver) → אושרה
```
- כל מאשר מסמן `אושר` לפי סדר.
- **Shortcut**: אם ה**מאשר האחרון** מאשר — המערכת **מדלגת** על
  הקודמים ברשימה.
- בסיום → סטטוס עובר אוטומטית ל-`אושרה`.

### 3.4 Status metadata — 15 דגלים per status
Dialog `מאפייני סטטוס`. דוגמה עבור `אושרה`:

| Flag | דוגמה ב-`אושרה` | תפקיד |
|---|---|---|
| `allow_changes` | ☐ | לאפשר לבצע שינויים |
| `allows_gr` | ☑ | לאפשר קבלה למלאי |
| `is_approved` | ☑ | הזמנה מאושרת |
| `is_closed` | ☐ | הזמנה סגורה |
| `is_status_on_close` | ☐ | סטטוס בסגירת הזמנה |
| `is_status_on_reopen` | ☐ | סטטוס בפתיחה חוזרת |
| `sends_email` | ☑ | שליחת מייל אלקטרוני |
| `is_post_approval` | ☑ | סטטוס לאחר אישור |
| `is_status_on_approval_cancel` | ☐ | סטטוס בביטול אישור |
| `is_cancelled` | ☐ | מבוטלת |
| `exclude_from_reports` | ☐ | להוציא מדו"חות |
| `duplicate_attachments_to_final` | ☐ | שני נספחים בת.סופית |
| `matrix_skip` | ☐ | דילוג מטריצה |
| `external_update` | ☐ | עדכון חיצוני |
| `included_in_tasks` | ☑ | נכלל בנושאים לביצוע |
| `name_en` | `Authorized` | שם באנגלית |
| `color` | — | צבע ב-graph editor |
| `note` | — | הערת admin |

### 3.5 State machine — 10 סטטוסים + transitions
State-machine editor ויזואלי (right-click → `חוקים` / `מאפיינים` /
`קבע צבע` / `שנה שם` / `עדכן הערה` / `מחק` / `סטטוס התחלתי` /
`ברירת מחדל לסטטוס התחלתי`).

```text
                      טיוטא (initial, green)
                    ╱   │   ╲
           פרפורמה  מחכה לאישור  מבוטלת
                        │  ▲
             (BPM rule) ↓  │
                      אושרה ─────→ מבוטלת
                        │  │
                        │  └─→ מחכה לאישור (re-submit)
                        ↓
                      נשלחה
                        │
                        ↓
                  אישור משלוח
                        │
                        ↓
                      באוניה
                        │
                        ↓
                   הגעה חלקית
                        │
                        ↓
                      סגורה ←── פתיחה חוזרת
```

10 סטטוסים + action-state `פתיחה חוזרת`.

### 3.6 BPM rules ברמת transition
דוגמה: *"רק יואב יכול להעביר ל-`אושרה` כל עוד המחיר בהזמנה קטן מ-
10,000."* אדמין מגדיר ב-graph editor (חצים אדומים = מוגבלים).

### 3.7 `ניהול תהליך מספק להזמנת רכש` (direct action)
פתיחת ה-graph editor מתוך ה-PO — רואים מאפייני סטטוס + חוקים.

### 3.8 Bypass
אם לא מוגדרת `רשימת מאשרים` — המערכת מתעלמת ומתחשבת רק בסטטוס.

### 3.9 BPM מלא (אלטרנטיבה)
רוחב יתרה של Priority — Rules engine + Notifications.

### 3.10 Print
Direct action `הדפסת הזמנת רכש` → בחירת תצורה.

## פרק 5 — המשך טיפול (08:31–10:16)

### 5.1 Auto-close conditions
PO נסגר אוטומטית כאשר הסחורה נקלטת דרך:
- **`תעודת קבלת סחורה מספק`** (GR), או
- **`חשבונית ספק`** (SI).

Linking ידני או אוטומטי.

### 5.2 Line updates
- `יתרה לאספקה` = `ordered_qty − received_qty`.
- דגל `סגורה` ברמת שורה כשנסגרה.
- דגל `סגורה` ברמת header כשכל השורות סגורות.

### 5.3 `מעקב תנועות` sub-screen
GR + SI movements per line (drill).

### 5.4 Reports — תפריט `דו"חות הזמנות רכש`
- **`הזמנות פתוחות – ספקים`** — open POs grouped by supplier.
- **`פיגורים באספקות`** — lines past `ת. אספקה`, shows `ימי פיגור`.
  דוגמה מ-reference:

  ```
  ספק 02092013 — שלחני אוכל קמפוז הישנה
  PO16000004  1  1923  שלחן...אובלי  1  —  1  יח'  09/03/16  5

  ספק 21122012 — עפרונות יואב בע"מ
  PO16000003  1  1921  עפרון אדום    5  —  5  יח'  08/03/16  6
  PO16000003  2  1920  עפרון רגיל   10  —  10 יח'  08/03/16  6
  ```

### 5.5 Analytics — תפריט `ניתוח הזמנות רכש` (8 פריטים)
- `הכנת סיכום הזמנות רכש` — aggregates.
- `הוצאת עוד לה. רכש` — export.
- `טיפוס הזמנות רכש` — report type config.
- **`מחולל דו"חות הזמנות רכש`** — custom report builder.
- `הכנת מלונית הזמנות רכש (BI)` — BI prep.
- **`ניתוח הזמנות רכש (BI)`** — BI cube.
- `אשף מחולל דו"חות` — report wizard.
- `אשף דו"חות מנהלים` — manager reports wizard.

### 5.6 Report invocation dialog
Modal עם radio: שמור / חדש / דו"ח / הדפסה / Excel / גיוון / טעינה.
Saved queries (parameter sets) ניתנות לריצה חוזרת.

### 5.7 Wizards
`אשף הזמנות רכש` — מוזכר בתפריט כ-guided flow.
