# Onboarding Master Data Templates — 8 תבניות קליטה

> **מקור גולמי**: 8 צילומי מסך של תבניות Excel-like לקליטת Master Data למערכת Priority.
> **תאריך קליטה**: 2026-04-26.
> **סטטוס**: ארכיון — זהו המקור הקנוני לשדות ולמבנה של Master Data. שימש ל-`master-data-onboarding-plan.md`.

---

## קונבנציות תבניות Priority

בכל תבנית יש שורות כותרת קבועות:

| שורת כותרת | משמעות |
|---|---|
| **כותרת חדשה** | שם השדה ב-UI |
| **טיפוס** | `CHAR` (טקסט שמאלי-ימני/LTR), `RCHAR` (טקסט רגיל/RTL), `INT`, `DATE`, `REAL` |
| **רוחב** | מספר תווים/ספרות מקסימלי |
| **דיוק עשרוני** | רק לשדות `REAL` |
| **קריאה/חובה/יתרה** | `M`=mandatory, `R`=read-only, `Y`=balance field |
| **בולאני?** | האם השדה בולאני (דגל Y/N) |
| **הערות** | הנחיות מיוחדות |
| **דוגמה** | ערך לדוגמה מהפרויקט הספציפי |

## הקשר ל-`master-data-onboarding-plan.md`

כל נתון מהתבניות הללו מופיע ב-plan עם:
- מיפוי למצב DB
- פער
- פעולה מומלצת (migration / seed / ניהול UI)

אם התבנית כאן לא תואמת את ה-plan → **ה-plan מעדכן את עצמו, לא את התבניות** (התבניות הן archival).
